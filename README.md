# 护眼时光 · EyeCare

纯本地、无联网、无广告的 Android 护眼提醒应用，围绕 **20-20-20 法则**：每连续用眼 20 分钟，向 20 英尺（约 6 米）外远眺 20 秒。

- 包名：`com.java.myapplication`
- 技术栈：Kotlin + Jetpack Compose（MVVM，单 Activity）
- 支持 Android 7.0（API 24）及以上；编译 / 目标 API 35
- 数据只存本机 `SharedPreferences`，不联网、不上传、无第三方依赖

---

## 功能

| 页面 | 作用 |
|---|---|
| **计时** | 主界面。用眼 / 休息倒计时环与今日概览；到点可「开始休息 / 稍后再说」 |
| **科普** | 随机展示一条健康用眼知识 |
| **报告** | 日 / 周 / 月用眼与休息统计：柱状图、达标率、周期对比 |
| **设置** | 提醒时长、到点自动全屏、休息结束提示音（可选音源 + 振动）、久坐提醒、免打扰时段、夜间模式、提醒可靠性自检、「关于」（版本 / 仓库 / 免责声明） |

**计时流程**：工作倒计时归零 → 通知（可选全屏）→ 休息阶段 → 休息结束响一声提示音 + 静默记录 → 回到工作。休息结束的处理是幂等的（界面到点与系统闹钟同时到达也只处理一次）；全流程只有一个发声路径（`RestSoundPlayer` 播一次，通知永久静默）。

## 构建

需要 Android SDK + JDK 17（本机为 `java-17-openjdk-arm64`）：

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-arm64
export PATH="$JAVA_HOME/bin:$PATH"

./gradlew testDebugUnitTest --offline   # 单元测试（纯逻辑，无需真机）
./gradlew assembleDebug --offline       # 打包 Debug APK
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

`--offline` 适配无代理网络（依赖已在本地 Gradle 缓存）；`gradle.properties` 已关闭 AAPT2 守护进程以适配 proot 环境。单元测试覆盖免打扰时段判断与设置项解析 / 格式化等纯函数。

## 已知限制

| 现象 | 处理 |
|---|---|
| 「到点自动全屏」不弹 | Android 14+ 默认拒绝 `USE_FULL_SCREEN_INTENT`：去 **设置 → 提醒可靠性自检 → 全屏通知** 开启 |
| 到点完全没有提醒 | 检查通知权限、精确闹钟、电池优化（自检页逐项看） |
| 熄屏 / 重启后不再提醒 | 部分 ROM 禁止自启动：去 **应用管理 → 护眼时光 → 允许自启动** |
| 免打扰时段不生效 | 设计如此：免打扰只对久坐提醒生效，用眼 / 休息提醒不受影响 |
| 提示音没声音 | 检查系统**通知音量**（与短信、微信同档）；静音 / 勿扰时按设计不响；关闭提示音会连同振动一起停 |
| 休息结束不振动 | 振动走「通知」用途，跟随系统通知振动设置 |
| 休息结束响两声 | 音源选到了双脉冲文件：去设置页点「试听」确认，换内置单脉冲音（清音 / 柔音 / 沉音） |
| 统计数字偏少 | 统计保留最近 90 天；无记录的日子不计入达标率分母 |

## 设计边界

- 不联网、不上报，不申请与核心功能无关的权限；不需要摄像头、悬浮窗、无障碍权限。
- 全流程只有一个发声路径（v2.3.10 起）：提示音由 `RestSoundPlayer` 播一次，通知永久静默。
- 不含医疗建议：本应用是习惯提醒工具，不提供诊断或治疗方案。
- 卸载即清除全部本地数据（SharedPreferences）。
