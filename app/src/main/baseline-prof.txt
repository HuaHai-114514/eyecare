# 手写基线配置文件（Baseline Profile）。
#
# 为什么需要它：没有 baseline profile 时，APK 首次执行任何方法都走解释器，
# 只有等 JIT 热起来才有原生代码。用户报的「冷启动第一次切页面掉帧、以后正常」
# 正是这个签名 —— 第一次切换要现解释执行 Pager 的测量、弹簧动画与整页组合。
#
# 这里只覆盖 App 自己的冷启动 + 首次切换热点；Compose / AndroidX 各自
# 自带 baseline-prof.txt，构建时会自动合并，不在这里重复。
#
# 格式：HSPL<class>->(<method>)
#   H = hot, S = startup, P = post-startup, L = loaded
#
# 说明：这是**手写** profile，不是设备采样生成的。它只把已知的启动与
# 首次切换链路标记为 AOT 编译，效果弱于真机采样，但不会影响正确性
# （profile 只影响编译策略，不影响行为）。
