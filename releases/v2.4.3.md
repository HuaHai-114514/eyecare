## 修复：快到点 / 到点未休息时息屏，亮屏误弹「超时」提醒

**现象**
用眼倒计时快到点、或已经到点但没点「去休息」时息屏，再次亮屏会弹出超时提醒——息屏期间人已经离开，不该被判为「超时未休息」。

**根因**
EyeTimer.onScreenOff 在「到点未休息」的超时态（awaitingRest = true）下只暂停累计、不清超时标记。亮屏时 onScreenOn 看到 awaitingRest 仍为 true，就直接恢复超时累计并重排超时闹钟，于是弹出超时提醒。

**修复（只改 timer/EyeTimer.kt）**
- 息屏阈值 LONG_OFF_RESET_MS：5 分钟 → 1 分钟
- 息屏 ≥ 1 分钟：先把当前用眼段结算进统计，再整体清零；亮屏从 0 重新计时
- 息屏 < 1 分钟：视为「短暂离开」，回来续算剩余时间，不毁进度
- 「到点未休息」时息屏 ≥ 1 分钟：结算超时段入统计 → 作废超时态 → 亮屏无任何提示，安静从 0 起算
- 超时提醒本身：息屏时冻结 + 撤销闹钟，只在亮屏且持续未休息时才弹
- resync 同步按新阈值判定「续算 / 清零」

**修复后行为对照**

| 场景 | 行为 |
|---|---|
| 快到点，息屏 < 1 分钟 | 回来续算剩余时间，到点发「该休息了」横幅（不弹超时） |
| 快到点，息屏 ≥ 1 分钟 | 结算已用时长 → 清零，亮屏从 0 重新计 |
| 到点未休息，息屏 ≥ 1 分钟 | 结算超时段 → 作废超时态，亮屏静默从 0 起算 |
| 到点未休息，息屏 < 1 分钟 | 回来续算超时（短暂离开不毁进度） |
