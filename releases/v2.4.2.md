## 修复：Android 15/16 上「到点自动全屏」失效

**根因（两层）**
1. **系统行为变更**：Android 15（API 35）起，`setFullScreenIntent` 在**亮屏解锁**状态下不再自动拉起全屏界面，只会退化成普通横幅——调通知参数无法绕过。
2. **未声明悬浮窗权限**：`AndroidManifest.xml` 里没有 `SYSTEM_ALERT_WINDOW`，导致系统设置里**根本看不到悬浮窗开关**。

**方案：悬浮窗 + 前台服务 + 自绘全屏 Overlay**
- 新增 `notify/RestOverlayService`（前台服务 + `TYPE_APPLICATION_OVERLAY` 自绘全屏休息页）
- `timer/EyeTimer.onWorkDeadline` 到点时按条件分流：
  - 开关关闭 / 息屏 → 不动
  - 前台 → App 内休息页
  - 后台 + 亮屏 + 有权限 → `beginRest` + 全屏 Overlay
  - 后台 + 无权限 → 降级横幅
- 新增 `AppForeground` 前台标记；各出口调用 `stop()` 防止叠层残留
- 「到点自动全屏」开关开启前弹**二次确认**
- 自检页新增「悬浮窗（后台全屏）」项 + 授权引导

## 补充：后台全屏休息页补上圆环进度条
首版 Overlay 只画了静态倒计时大数字，漏了圆环进度条（App 内休息页有、后台覆盖没有，视觉不一致）。新增原生 Canvas 自绘的 `ProgressRingView`：轨道 + 从 12 点顺时针推进的进度弧，弧色随进度 绿→橙→红，与 Compose 端 `EyeProgressRing` 同一视觉语义；每秒随倒计时刷新。
